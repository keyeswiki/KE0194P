**校准舵机所需额外零件**

![](./media/D1.png)

所需线材：

![](./media/2p-200.png)

- 2PIN 母对母杜邦线 颜色随机

| 舵机 | 舵机控制模块 |
| :--: | :----------: |
| 棕线 |      G       |
| 红线 |      V       |
| 橙线 |      S       |

| 舵机控制模块 | 扩展板 |
| :----------: | :----: |
|      5V      |   5V   |
|      G       |   G    |

![](./media/D2.png)

电池安装示范:
